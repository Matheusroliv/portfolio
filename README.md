# Portfólio – Matheus Oliveira

Aplicação construída com **Vite + React + TypeScript**, Tailwind CSS e shadcn-ui.

## Scripts

| comando | descrição                    |
|---------|-----------------------------|
| `npm run dev` | inicia ambiente de desenvolvimento |
| `npm run build` | gera build de produção |
| `npm run preview` | serve o build gerado |

## Tecnologias principais

- React 18
- TypeScript 5
- Tailwind CSS 3
- shadcn-ui
- React Router 6
- TanStack Query 5

## Deploy

O projeto pode ser publicado facilmente no Vercel, Netlify ou qualquer serviço estático que suporte apps Vite.
